# Prompt 1: choose a project name

Use it in an ordinary Claude chat, before the project exists. Fill in the angle brackets first.

---
I am starting a project in which I work with Claude to <plan and document my home lab / build something / learn something>. Every conversation will be logged to a GitHub repository, and the project will carry the same name on both sides: a Claude.ai project and a GitHub repository.

Help me choose the name. Before suggesting anything, ask me up to three questions, one at a time, about what the project is for and what words appeal to me.

Then give me eight candidates in a table with: the Claude.ai project name (spaces allowed), the repository name (letters, digits, and hyphens only), and a one-line reason. Judge each against these tests:
1. It says what the project is about or what it will produce, not just what it is made of. Hardware changes; purpose lasts.
2. It is not generic: a search of GitHub for it should not drown in unrelated repositories.
3. It is short, easy to type, and easy to say aloud.
4. It stays accurate if the project grows.
5. The repository name and the project name are recognizably the same.

Mark your top two and explain the tradeoff between them. I will check GitHub for availability myself.
---
